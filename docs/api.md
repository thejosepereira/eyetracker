# API Reference

Base URL (local): `http://localhost:8000`
Interactive docs: `GET /docs` (Swagger) — auto-generated by FastAPI.

## `GET /health`

```json
{ "status": "ok", "service": "VisionCorrect API", "version": "0.1.0" }
```

## `POST /v1/correct`

Returns the **pre-compensated image** to display on screen.

`Content-Type: multipart/form-data`

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| `image` | file | — | **required** |
| `sphere` | float | — | **required**, dioptres (negative = myopia) |
| `cylinder` | float | `0.0` | dioptres, minus-cyl convention |
| `axis` | float | `0.0` | degrees, 0–180 |
| `viewing_distance_mm` | float | `350` | |
| `ppi` | float | `264` | screen pixels-per-inch |
| `correction_strength` | float | `1.0` | scales the estimated blur |
| `regularization` | float | `0.012` | Wiener K (higher = softer/safer) |
| `dynamic_range` | float | `0.55` | target contrast headroom (lower = sharper, flatter) |
| `contrast_boost` | float | `1.0` | final perceptual contrast |

Query param `response`:
- `png` (default) → raw `image/png` body.
- `json` →

```json
{
  "success": true,
  "processing_ms": 84,
  "profile": { "sphere": -2.5, "cylinder": -1.0, "axis": 110 },
  "blur": { "sigma_x": 9.09, "sigma_y": 12.73, "angle_degrees": 110,
            "psf_width": 77, "psf_height": 77, "clipped_fraction": 0.082 },
  "output_base64": "data:image/png;base64,…"
}
```

### Example

```bash
curl -X POST "http://localhost:8000/v1/correct" \
  -F image=@photo.jpg -F sphere=-2.5 -F cylinder=-1.0 -F axis=110 \
  --output corrected.png
```

## `POST /v1/demo`

Same form fields as `/v1/correct`. Returns four base64 PNG panels plus blur
metadata — used by the browser demo to show before/after. The `uncorrected` and
`corrected` panels are **eye simulations** so the effect is visible without
having the prescription.

```json
{
  "original": "data:image/png;base64,…",
  "uncorrected": "data:image/png;base64,…",
  "precompensated": "data:image/png;base64,…",
  "corrected": "data:image/png;base64,…",
  "blur": { … },
  "processing_ms": 120
}
```

## Errors

| Status | Meaning |
|--------|---------|
| `400` | image could not be decoded |
| `422` | invalid prescription (out of range) or missing required field |
